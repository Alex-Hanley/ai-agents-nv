[2:00] WHAT IS TOKEN FACTORY
[SCREEN: screencast, tokenfactory.nebius.com landing page]

So what is Token Factory?

Open language models publish their weights. In principle you can download
them and run them on your own hardware. In practice that takes GPU clusters,
a serving stack, scaling, monitoring. It's a lot of infrastructure before you
get your first useful answer.

Token Factory is managed inference. Nebius runs the models, and you send a
request and get an answer. The whole interface is one URL and one API key.

[SCREEN: screencast, hover over pricing / serverless mention]

In this course we use serverless inference. That means public models, ready
immediately, billed per token. You pay for exactly what you use, nothing
while you're idle. There are also dedicated endpoints where you rent GPUs
directly, but nothing in this course needs that.

That "billed per token" part matters. Every request has a price attached, and
in notebook 3 we'll learn to calculate it. For now just register the model:
tokens in, tokens out, and a meter running.

[4:00] THE NEMOTRON FAMILY
[SCREEN: deck 02, slide 1 (title)]

Nemotron is NVIDIA's family of open language models, and it's the family we
use for every example in this course.

[SCREEN: deck 02, slide 2 (what Nemotron is)]

Three things to know about it.

The models are open. The weights are published under an open license, so they
can be downloaded, studied, and fine-tuned. Later in the course, we'll
actually do that fine-tuning.

They're trained for agent work. Tool calling and reasoning are trained into
these models, and those are exactly the two capabilities this whole course is
built around. That's why they're our running example.

And they're on Token Factory, serverless. No setup beyond the API key you'll
create in notebook 1.

[5:00] THREE SIZES
[SCREEN: deck 02, slide 3 (Nano, Super, Ultra)]

The family comes in three sizes: Nano, Super, and Ultra. Size affects three
things: how fast the model responds, what it costs per token, and how much
reasoning depth it has.

Nano is the smallest and fastest, and it's the model we use in all three
notebooks. Six cents per million input tokens, twenty-four cents per million
output tokens. You can run it all day while you learn and barely see a bill.

Super is the mid-size model, a common production choice when Nano's output
isn't enough for a task.

Ultra is the largest, with the strongest reasoning, at a dollar in and three
dollars out per million.

[SCREEN: deck 02, slide 4 (matching model size to the task)]

Which one you'd pick depends on the workload. High-volume everyday tasks,
drafting, classification, quick answers: Nano handles those well. Complex
multi-step reasoning where a wrong answer is expensive: that's where Ultra
earns its price. Super sits between.

You'll make this comparison yourself in the playground, side by side, in the
next video. The information you need to decide lives on each model's card,
and reading that card is exactly where we pick up.
